11. **Formula recalculation.** A macro that changes a cell does not change the displayed value of formulas that depend on it; the adapter keeps the cached value. The grid says so on every sheet that has a formula. A small evaluator for the common functions (`SUM`, `IF`, `VLOOKUP`, arithmetic) would remove the note on most business workbooks.
12. **Number formats.** The grid shows stored values (dates as serial numbers, currency as plain numbers). Reading `numFmt` from the file and formatting dates, percentages and currency would make the grid look like the sheet in Excel.
13. **Trace "Go to cell" and "Go to line" on narrow screens act on the selected row.** The spec asks for the two controls on every trace row. A button inside a `role="option"` row is a nested interactive control that axe reports, so the controls sit under the list and apply to the selected row. Revisit if the trace list becomes a grid or a table.
14. **Buttons in `.xls` files.** `readButtons` reads only the ZIP formats. In a `.xls` the buttons are BIFF `OBJ` records (with the macro name in a following formula record); they are not read, and the UI says nothing about them. A reader for those records would list them in "Buttons on sheets" like the others.
